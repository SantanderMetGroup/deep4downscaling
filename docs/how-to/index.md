# How-to guides

How-to guides are short, task-oriented pages for solving specific problems. Unlike [tutorials](../tutorials/index.md), they assume you already understand the basics.

## Available guides

| Guide | Task |
| --- | --- |
| [CORDEXBench workflow](cordexbench.md) | Reproduce benchmark experiments |
| [Canary Islands domain](canary-islands.md) | Adapt workflows to a regional domain |
| [Resume training](resume-training.md) | Continue training from a checkpoint |
| [Add a custom loss](custom-loss.md) | Implement and register a new loss function |

## When to use a how-to vs. a tutorial

- **Tutorial** — you are learning the library and want a guided, end-to-end narrative
- **How-to** — you know what you want to achieve and need the steps quickly
- **User guide** — you want to understand *why* something works a certain way
- **API reference** — you need exact parameter names and return types
